# Changelog

What changed in each release of Dropwheel for Windows and Linux. The release workflow copies a version's section into its
GitHub release, and **Settings › System › Check for updates** shows it as "What's new" before updating.

Before tagging `desktop-vX.Y.Z`, add a `## [X.Y.Z]` section at the top. The release fails if it's missing.

## [1.5.0]

- **First Dropwheel release for Windows and Linux**: the global drag wheel with Convert, Tools and Actions, compression, archives,
  crop and trim, OCR, PDF tools and password protection. Settings and tools live in a `Dropwheel` folder in your user profile.
- **Updates**: Check for updates reads Dropwheel's Windows and Linux releases (tagged `desktop-v…`) and ignores the Mac app's releases.
